რაც თურმე leakaging არის და მაგასთან ბრძოლა დამჭირდა. წავშალე column ები რომელიც ამას მიქნიდნენ. ვცადე მაქსიმალურად რომ ერთი და იგივე ინფორმაციაზე არ ყოფილიყო დატრენინგება და ამისთვის სხვადასხვა ხერხი გამოვიყენე. 
საბოლოოდ F1-score არც ისე მაღალი გამომივიდა, თუმცა recall შედარებით მაღალი და tresholdის 0.82მდე აწევით F1 გახდებოდა 0.34 დაახლოებით. თუმცა მაგ მომენტისთვის უკეთესი მოდელებიც მქონდა და თან არაბალანსირებული Y დიდად არ ერგება რეგრესიას და ამიტომაც მივატოვე ეს მოდელი.

# Random Forest

ამ მოდელშიც მინდოდა RandomizedSearchCV გაშვება ან რაიმე მსგავსის, მაგრამ სამწუხაროდ დატრენინგებას დიდი დრო სჭირდებოდა და ამის გამო ცალცალკე მომიწია გაშვება. თან kaggleზეც Ramის მეხსიერება აღარ მყოფნიდა. decision-treeში რაოდენობის შეცვლამ თუ მიშველა აქ ასე არ გამოდგა. თანაც საიტის რეფრეშის შემდეგ თავიდან გაშვება მიწევდა. ამიტომაც ცალცაკე ვუშვებდი და ვაკვირდებოდი მონაცემებს. თუმცა საბოლოო ჯამში ისევ overfitting ში წავედი. რის შემდეგაც პარამეტრები შევცვალე და მაშინვე underfitting ში ჩამოვედი. თუმცა საბოლოო ჯამში ვიპოვე ასე თი ისე კარგი პარამეტრები ამ მოდელისთვის ამ მომენტისთვის.
